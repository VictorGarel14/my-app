# VIC'TORY · charte de marque

Référence visuelle : `moodboard.jpg`. À utiliser pour toutes les applis, cartes et visuels.

- **Marque** : VIC'TORY (l'apostrophe est un éclair dans le logotype). Le voyage d'un rêveur qui transforme chaque jour en victoire. Un état d'esprit, une discipline, une collection.
- **Baseline** : IMPOSSIBLE IS JUST A DISTANCE.
- **Signature** : « continuer à rêver, juste assez pour tenir debout »
- **Accroche** : « Chaque jour est un pas vers l'impossible. »
- **Valeurs** : Détermination · Dépassement · Résilience · Rêve · Liberté
